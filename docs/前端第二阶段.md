# 第二阶段：项目基础与设计系统

本阶段仅修改前端及文档，没有修改 Python 后端。

## 结构

- `web/src/main.tsx`：React 入口；`App.tsx`：路由。
- `web/src/components/layout/LabLayout.tsx`：应用壳、导航及模式说明。
- `web/src/components/ui/`：符合 shadcn/ui 组织方式的 Button、Input、Switch；使用 Radix、CVA 与 Tailwind，支持后续通过 components.json 添加组件。
- `web/src/hooks/use-theme.ts`：默认深色，支持浅色与本地持久化。
- `web/src/pages/LegacyWorkbench.tsx`：从原 JSX 迁移的真实工作台，保留上传、生成、下载、提取与检测占位。
- `web/src/pages/StagePlaceholder.tsx`：后续页面的明确阶段提示与可用工作台入口。
- `web/src/services/api.ts`：Axios 对接现有 Python 基线；尚未切换到规划的 FastAPI 接口。
- `web/src/styles.css`：Tailwind v4、双主题变量、键盘焦点、减少动态效果与应用样式。
- `web/tsconfig.json`：严格 TypeScript；`components.json`：shadcn/ui 配置。

## 路由与运行

开发运行：在 web 目录执行 `npm run dev`；后端仍按原方式执行 `python app.py`。

访问 http://127.0.0.1:5173/#/workbench 可继续体验已有功能。采用 HashRouter 使现有静态 Python 服务无需更改即可刷新路由。正式 FastAPI 部署确定回退规则后可改 BrowserRouter。

`/`、`/qr`、`/hide`、`/extract`、`/detect`、`/tamper`、`/robustness`、`/compare` 为后续分阶段开发的位置，本阶段不声称对应完整功能已完成。

## 依赖与边界

已安装 React Router、Axios、Lucide、Motion、ECharts、Tailwind v4、TypeScript、Radix 与 shadcn 基础工具。Motion 和 ECharts 留待对应功能阶段使用。

`.env.example` 记录环境变量规划。目前工作台固定走真实基线 API；Mock 数据、切换和接口类型将在第六阶段完成，当前不应设置 VITE_USE_MOCK=true。未输出演示指标或伪造成功状态。

## 验证

`npm run typecheck`：严格类型检查。

`npm run build`：先检查类型再生成生产资源。

浏览器验收：切换浅色并刷新验证持久化；逐项导航并查看当前阶段提示；打开现有工作台，生成 PNG 后上传、使用相同密钥提取；缩小窗口检查导航可滚动、工作台单列显示；键盘 Tab 可访问导航与主题开关。

第三阶段才开展完整互动首页与导航细节优化。
