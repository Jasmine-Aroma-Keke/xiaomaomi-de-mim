## 发现的运行环境问题

最初前后端端口未能访问，随后启动服务。本机检查确认 127.0.0.1:8000 和 127.0.0.1:5173 存在监听；重复启动 Vite 提示 5173 已占用。普通沙箱访问出现 WinError 10013；经提升权限重试，并明确绕过环境代理直连后，仍然连接超时。

因此本轮 HTTP 失败不能归因为算法失败，也不能简单宣称启动后已解决。没有关闭防火墙或削弱系统网络保护。需要在用户本机终端/浏览器确认 localhost 可访问后重跑。

## 复现

在项目根目录启动 `python app.py`；另开终端 `cd web` 后 `npm run dev`。用浏览器确认 http://127.0.0.1:5173 与 http://127.0.0.1:8000 可达。

```powershell
python tests/verify_mvp_http.py
npm --prefix web test
npm --prefix web run build
python -m unittest discover -s tests -v
```

原始 HTTP 结果：outputs/mvp_http_results.json；无网络请求处理结果：outputs/mvp_inprocess_results.json；生成的实测 PNG：outputs/mvp_inprocess.png。outputs 被 Git 忽略，正式交付时另行保留所需证据。
