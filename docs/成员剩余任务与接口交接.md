## 3. 现有 HTTP 接口：现在可以调用

开发前端 127.0.0.1:5173，代理 /api 到 127.0.0.1:8000。JSON 请求，UTF-8；png 字段仅 Base64，不带 data:image/png;base64, 前缀。

### POST /api/generate

```json
{"public":"https://example.com","secret":"来自喵星人的问候","key":""}
```

- public：必填，1–1200 UTF-8 字节；secret 默认空，最大 11960 字节；key 默认空。
- 空 key 为顺序 LSB；非空 key 为置乱 LSB。当前没有 algorithm、image、region、纠错等级或尺寸输入字段。
- 返回：`{"png":"<Base64>","capacity_bytes":11960,"scan_status":"unverified"}`。
- 内置猫咪，输出 RGB PNG；不能宣称用户上传猫图已参与生成。生成也不代表扫码已验证。

### POST /api/extract

```json
{"png":"<Base64>","key":"嵌入时的密钥"}
```

返回示例：

```json
{"status":"passed","secret":"来自喵星人的问候","detail":"消息完整；不代表整幅图像完整"}
```

status：passed / failed / unknown。失败/未知时 secret 为 null。错误密钥、无标记、图像损坏可能同为 unknown，不能据此断言恶意篡改。接受 PNG，最大 400 万像素；前端限制文件 5.5 MB，HTTP 请求体上限 8,000,000 字节。

### POST /api/detect

输入 `{"png":"<Base64>"}`。当前返回 `{"status":"unavailable","detail":"等待 C 接入统计检测，提取成功不能用作隐写检测结论"}`，没有真实卡方或 RS 结果。

### 错误约定与现有限制

正常 200；已处理输入错误 400，JSON `{"error":"说明"}`；未知路由 404（当前可能为 HTML，前端按状态处理）。客户端 Axios 超时 30 秒。当前服务不是完整生产级参数验证；成员接入 FastAPI 时需补齐类型验证、统一错误封包，不应依赖错误类型输入一定得到 400。

## 4. CAT1：必须兼容的现有载体

- 区域 x=[image.width-180,image.width-20)，y=[32,232)，RGB 通道，按 y→x→通道顺序取最低位。
- 160×200×3=96000 位；40 字节头，净载荷 11960 字节。
- 包头：ASCII CAT1（4）+ uint32 大端消息字节数（4）+ HMAC-SHA256(key,消息)（32）+ UTF-8 消息。
- 非空 key：SHA256(UTF8(key)) 转大端整数为 Python random.Random 种子，shuffle 整个位置列表；跨语言不能直接假设与其他随机数库一致。
- 不提供内容加密；空 key 无认证保密性。HMAC 仅覆盖消息，不覆盖整个图像。
- 改区域、封包或算法需新版本（拟 CAT2），先确定版本识别/算法ID/区域元数据/密钥派生；旧图不能默默按新规则读取。

## 5. Python 模块目标签名（待成员确认，不是已实现 API）

统一 Pillow RGB 图像；region=(x,y,width,height)，左上原点、右下边界不包含；protected_mask 真值代表禁止改动，尺寸与图像一致。

```python
# A：config 含猫图、纠错、尺寸/位置；字段与 A+B 确认后冻结
generate(public: str, config: dict) -> dict  # image, region, protected_mask, qr_version, correction
# B、G：算法版本放元数据，由组长适配公共服务
embed(image, secret: str, key: str, region: tuple) -> dict  # image, capacity_bytes, metadata
extract(image, key: str, region: tuple) -> dict  # status, secret, detail
# C
analyze(image, region: tuple, method: str = "chi_square") -> dict
# method, statistic, threshold, decision, calibration_id, limitations
# D
verify(image, metadata: dict, key: str) -> dict  # status, coverage, detail；可选经过认证的块结果
# E
evaluate(original, stego) -> dict  # psnr_db, ssim, width, height；注明 SSIM 窗口/通道/范围
# F
run(cases: list, config: dict) -> list[dict]  # 每次实验记录，不只交平均值
```

B/G 必须告诉组长：原始图从哪里来、是否返回独立元数据、如何恢复 region；不得要求提取端知道未提交的隐藏状态。容量不足使用 ValueError；依赖/算法不可用返回明确状态，不返回假成功。新字典中的图像对象不能直接 JSON 序列化，由服务层转 PNG Base64。

## 7. 实验交付格式

统一 CSV 列：sample_id,source,license,split,seed,algorithm,width,height,payload_bytes,capacity_bytes,embed_ms,extract_ms,psnr_db,ssim,attack,strength,scan_success,secret_success,integrity_status,detection_score,error。

未知留空或明确 unknown，不以零替代未测；无差异 PSNR 为 inf。扫码读到的文本与公开原文一致才成功；恢复 UTF-8 字节完全一致才成功。每种条件记录分子/分母、样本数、重复数与环境。密钥不写入 CSV/日志/公开仓库。前端现有端到端 CSV 不能替代 E 的规范纯算法实验数据。

## 8. 合并与验收顺序

1. A+B 冻结区域与包格式，交一组真扫码且可恢复的 PNG。
2. D 确定可信数据与覆盖范围；G 验证位置同步和版本。
3. C 固定统计定义与校准数据；E/F 跑批量实测。
4. 组长接入 core/service.py 与 web/src/services，跑回归、更新功能状态、整合本人 PPT。

每人用个人分支 feature/A-qr 等提交；不改其他成员模块。PR 包含依赖、命令、样例、测试与真实结果。至少跑：基础恢复、错误密钥、容量超限、PNG 重存、破坏消息位、输入损坏、扫码与提取分别验证。
