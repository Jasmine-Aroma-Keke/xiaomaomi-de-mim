# 第四阶段与侧边导航

修改范围仅前端，无后端变更。

## 已实现

- LabLayout：桌面固定侧栏，窄屏原生 dialog 抽屉，支持焦点约束、Escape 关闭、路由跳转自动关闭，保留主题开关。
- Creation：二维码生成和秘密隐藏共用参数组件；真实请求、图片预览、PNG 下载、UTF-8 字节数、容量检查、基础/随机算法、参数过期提醒、人工扫码确认。
- Extraction：PNG 拖拽/选择、算法和密钥、恢复文本、校验与未知状态、文本下载；改变输入清除旧结果。
- ImageUpload：共享上传组件，限制格式、文件大小和像素数，异步读取使用序号避免旧文件覆盖新选择。
- services/stego.ts 与 types/stego.ts：核心接口类型与响应检查，适配现有基线服务。
- utils/image-metrics.ts：浏览器实际 RGB 像素 PSNR 计算。
- App.tsx、styles.css：三个路由及响应式样式。

## 明确限制

现有 Python 生成器不接收自定义图片、纠错级别或尺寸，因此上传图片只供预览，选择后提示切回内置猫咪才能真实生成。纠错 H、猫咪宽度 200 固定显示。自适应算法禁用并标注待接入，SSIM 未计算。没有修改后端来假装支持这些参数。

PSNR 的参考图是同公开文本、同密钥、空消息的基线载体，比较含密图的真实 RGB 差异；不是未嵌入封包的原始载体，界面明确说明。自动扫码验证未接入，人工确认标注为用户核对。

基础 LSB 使用空密钥；随机 LSB 要求非空密钥。接口当前没有显式算法字段，适配器按现有 CAT1 规则发送密钥；任意新算法需要正式协议扩展。
