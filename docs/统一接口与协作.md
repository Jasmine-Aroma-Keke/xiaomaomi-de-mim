# 统一接口与协作规范 v1

## 架构

浏览器 → app.py JSON API → core/service.py → 各成员模块。前端只依赖服务协议；由组长修改 service.py 适配成员模块。Pillow RGB 图像为内部载体，输出 PNG；禁止在中间环节 JPEG 保存、缩放或量化。

## API

| 路由 | JSON 输入 | JSON 输出 |
|---|---|---|
| POST /api/generate | public, secret, key（UTF-8 文本） | png（无前缀 Base64）、capacity_bytes、scan_status |
| POST /api/extract | png、key | status、secret、detail |
| POST /api/detect | png | status、detail；C 接入后附 method/statistic/score |

成功 HTTP 200，输入错误 400，未知路由 404。不能将不可用或无法判断映射成通过。完整性状态 passed/failed/unknown；检测未接入为 unavailable。密钥不写入文件、CSV 或日志。

## 成员模块接入目标

以下为统一目标签名，成员确认后由组长通过适配器接入，并非已存在的实现。

| 成员 | 文件与接口 | 必须返回/说明 |
|---|---|---|
| A | core/qr_generator.py: generate(public, config) | image, region, protected_mask；区域坐标与容量；二维码版本与纠错等级 |
| B | core/steganography.py: embed(image, secret, key, region); extract(image,key,region) | RGB image；提取状态、文本、校验结果 |
| C | core/steganalysis.py: analyze(image,region) | method, statistic, score, threshold, decision；阈值来源与局限 |
| D | core/tamper_detector.py: verify(image,metadata,key) | passed/failed/unknown, coverage；说明校验对象及依赖的可信元数据 |
| E | experiments/metrics.py: evaluate(original,stego) | PSNR dB、SSIM、有效载荷字节、耗时 ms |
| F | experiments/robustness.py: run(cases,config) | 每次攻击的原始记录；扫码、恢复、校验分别统计 |
| G | core/adaptive_steganography.py | 与 B 相同签名；方法标识与位置复现规则 |

region=(x,y,width,height)，左上原点，右/下边界不包含；mask 真值为禁止改动区域。A 融合方案更换区域后必须升级载体版本，不能用旧解析规则读取。

## 当前 CAT1 载体协议

右侧 200px 为猫咪条带；隐藏区域 x=[width-180,width-20)，y=[32,232)，RGB 三通道，逐通道最低位。共 96000 位。按 y、x、channel 遍历；有密钥时使用 SHA256(UTF8(key)) 转大端整数作为 Python Random 种子置乱。

包：4 字节 ASCII CAT1 + 4 字节大端无符号消息字节数 + 32 字节 HMAC-SHA256(key,message) + UTF-8 消息。容量 11960 字节。无持久化位置元数据，裁剪、旋转、尺寸改变会破坏解析。改进版统一预留 CAT2，先讨论元数据自描述、算法 ID、区域、随机数算法及密钥派生，禁止悄悄改变 CAT1。

## 实验数据格式

CSV 一行一次运行，列：sample_id,source,license,split,seed,algorithm,width,height,payload_bytes,capacity_bytes,embed_ms,extract_ms,psnr_db,ssim,attack,strength,scan_success,secret_success,integrity_status,detection_score,error。

未知值留空，失败写原因；PSNR 无差异用 inf；没有实测不得写 0 代替。扫码成功按读取内容与公开原文一致判定，秘密成功按 UTF-8 原文字节完全一致判定。检测统计以含密标签计算混淆矩阵，训练/阈值集和评估集分开，避免同源图片泄漏。报告分子、分母与样本数。

## Git 与提交

分支 feature/A-qr、feature/B-lsb 等；组长维护 integration。每人只改负责文件，公共协议改动先登记。提交 PR 包括依赖、调用示例、正常/边界/异常测试、实测样例和本人 PPT 内容。不得提交密钥、私人图片、.deps、缓存。合并前运行组长回归，检查扫描和恢复两条流程。冲突由模块负责人和组长共同处理。

## 联调顺序

先 A+B 确认 region 和扫码，再 D 确认校验覆盖，再 G 确认提取同步，最后 C/E/F 固定种子开展实验。每次更换算法重新验证：公开扫码、PNG 恢复、错误密钥、容量超限、秘密位篡改、输入损坏、检测不可用状态。
