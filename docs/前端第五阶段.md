# 第五阶段：检测与实验页面

本阶段没有修改后端，没有填充演示指标。Mock 与环境切换仍留待第六阶段统一实现。

## 文件与功能

- `web/src/pages/Detection.tsx`：待测图与参考图、方法选择、整图 RGB 直方图、可访问数据表；调用现有 `/api/detect` 并保留 unavailable 状态。卡方方法仍无真实统计量，RS 接口未约定，不伪造风险分数。
- `web/src/pages/TamperDetection.tsx`：现有 CAT1 消息校验、同尺寸参考图 RGB 差异、差异热力图、文本报告导出。参考图可信性由用户确认，不声称整图认证或恶意篡改判定。差异不检查 alpha 通道。
- `web/src/pages/Robustness.tsx`：JPEG、高斯噪声、椒盐噪声、裁剪、旋转、遮挡；强度可调，显示明确参数；实际处理、前后图和结果导出。原图及处理后都调用提取，只有原文一致且校验通过才报告恢复成功。
- `web/src/pages/AlgorithmComparison.tsx`：基础/随机 LSB 真实调用对比，按算法选择，按指标切换 ECharts，数据表与 CSV。记录端到端生成/嵌入及提取耗时、PSNR、容量、恢复和 JPEG 干扰结果。SSIM、统计检测尚无结果。
- `web/src/components/charts/LabChart.tsx`：ECharts 按组件注册，主题变化重绘，尺寸变化自适应，卸载销毁。
- `web/src/utils/experiments.ts`：真实像素统计、RGB 差异、攻击操作、文件导出；噪声固定种子 20261107。
- `web/src/App.tsx`：四个页面路由与懒加载。
- `web/src/styles.css`：图表、表格、报告与窄屏样式。
- `web/src/components/upload/ImageUpload.tsx`：修复连续选文件时无效文件可能保留读取状态的问题。

## 实验条件

JPEG 强度 s 对应质量 1-0.95s，先浏览器 JPEG 编码再解码为 PNG，避免当前后端拒绝 JPEG。旋转最大 45 度，保持画布尺寸、白底；裁剪四边各最多 20%，不缩放；遮挡中心区域边长最多 50%；高斯噪声最大标准差 40；椒盐替换概率最多 30%。强度零不改像素。不同浏览器的 JPEG 编码器可能不同，正式跨环境复现需要固定浏览器版本。

PSNR 基线为相同参数空消息 CAT1 载体，并不是未嵌入包头的原图。每个算法仅一例；耗时包含 HTTP 与后端处理，不能据此声称统计显著或纯算法性能优劣。无穷大 PSNR 在表格/CSV 保留，图表留空；unknown 保持未知，不映射成 0。

## 接口边界

已使用的仍然是现有 `/api/generate`、`/api/extract`、`/api/detect`。未新增、未假设 FastAPI 检测/实验接口。公开扫码始终为未验证，自动接口待接入。完整性依旧仅验证消息封包，不替代 D 的整图或分块机制。

## 验证

- TypeScript 严格检查与 Vite 生产构建通过。
- 浏览器真实运行基础、随机 LSB 对比，两个算法均成功恢复同一中文/emoji 文本。
- 浏览器截图检查 ECharts 显示真实结果，表格保留数值与未知状态。
- 对比流程实际执行了 JPEG 编码/解码及后端提取，结果保留无法判断状态。

六类干扰的完整边界回归、参考图上传流程和各尺寸验收留待第六阶段，不声称已经完成全部交互测试。构建存在 500 KB 包体积提示；实验路由和图表已独立加载，仍可继续优化首页依赖。
