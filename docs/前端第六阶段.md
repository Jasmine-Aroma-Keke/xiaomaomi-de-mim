# 第六阶段：模式、测试与优化

本阶段只修改前端、测试、依赖及说明，没有修改 Python 后端。

## 交付

- services/config.ts、mocks/lab.ts：VITE_USE_MOCK 模式开关和确定性会话演示，演示不联网、不冒充真实隐写。
- services/api.ts、services/stego.ts：超时、网络、404、HTTP 错误与响应格式校验。
- components/common/ErrorBoundary.tsx：页面加载或渲染异常的中文恢复入口。
- LabLayout、Creation、Extraction、AlgorithmComparison、导出工具：全局演示提示、带来源的下载、演示图禁止扫码确认、演示模式不发布实验指标。
- App.tsx、vite.config.ts：首页/工作台懒加载，图表引擎分包。
- tests/、vitest.config.ts：22 项前端自动化测试。
- .env.demo、.env.example、package.json：独立演示开发与构建命令；README 和 API 文档补充。
